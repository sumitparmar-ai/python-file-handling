# Python File Handling

A beginner-friendly Python project created to practice and understand file handling operations in Python.

## 📌 About the Project

This project demonstrates how Python can be used to work with files and perform basic file operations such as reading, writing, and appending data.

## 🛠️ Technologies Used

* Python
* File Handling

## 📚 Concepts Covered

* Opening files
* Reading file contents
* Writing data to files
* Appending data
* Different file modes
* Closing files
* Using `with open()` for safe file handling

## ⚙️ File Modes Used

| Mode | Purpose               |
| ---- | --------------------- |
| `r`  | Read a file           |
| `w`  | Write to a file       |
| `a`  | Append data to a file |
| `r+` | Read and write        |

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/sumitparmar-ai/python-file-handling.git
```

2. Open the project folder:

```bash
cd python-file-handling
```

3. Run the Python program:

```bash
python filename.py
```

Replace `filename.py` with the name of the Python file you want to run.
